# 直线楼梯与跳台组合

两类课程均沿 +X 前进，没有转弯：

- `stair_gap`（组合A）：起点平地 → 两个踏步 → 起跳平台 → 跨沟 → 落地平台；落台后完成任务。
- `stair_gap_ramp`（组合B）：相同的楼梯与跳跃 → 落地平台正前方下斜坡 → 终点平地。
- `gap_combos`：两类合训，各自维护成功率和难度前沿；两类也已加入 `robocon` / `robocon_mixed`。

有效赛道全程宽80cm，包括1.2m起点平地、32cm深的独立踏步、80×80cm起跳/落地平台和坡道；组合B另有1.2m终点平地。两侧和跳台缺口均下通5m深沟，不存在可侧绕的地面。平台等高，从地面经过两个独立踏步再到平台，共三次等高度抬升。组合A的末平台之后没有坡道或额外地面。

L6采用用户指定的比赛XML的楼梯与跳台尺寸，坡道改到正前方。L9的抬升高度、沟宽及坡角分别为比赛参数的约1.5倍；该定义不是整体运动难度或比赛成功率的倍数。坡长按平台高度和坡角计算，坡底接Z=0赛道；L9水平坡长约93.53cm。原XML下方地面和90度转弯不属于这两个训练版本，原XML文件未修改。

## 任务规则

### 组合任务奖励（2026-10-21）

两种组合均不额外奖励前进距离，沿用通用速度跟踪奖励引导前进。
第一、第二级台阶及起跳平台首次按顺序获得有效支撑，各奖励0.5；完整落台奖励2；
带坡组合首次在完整落台后有效支撑下坡奖励1；整段成功奖励由8降为4；违规失败奖励为−5。
阶段奖励均只触发一次，回合重置后重新记录。此处记录的是额外任务奖励，最终训练奖励还包含通用运动奖励与AMP混合。

整段任务中途不重置。必须依次获得两个独立踏步、起跳平台的顶面支撑，再腾空跳到相邻落地平台。允许四足先后接触目标台面，为各只脚分别记录有效接触；四足均完成接触且当前均位于目标台面XY范围内、至少两足有效支撑，才记录跳跃完成。不要求四足同一个控制步同时接触。

腾空和尚未落下的脚不判失败；落台时接触非目标平台、平台外接触、脚掉入缺口或侧沟、卡在台间、侧绕或坠落判失败并重置。足底判定保留2cm高度容差，台面边界保留5mm余量。每次落台的四足接触历史在下一跳前清空，不能跨平台累计。

组合A在落地平台稳定支撑0.3秒完成；组合B落台后继续，必须实际接触下坡，再完整进入坡底平地稳定支撑0.3秒完成。正常步态允许至少两足支撑。`coverage` 六列对组合任务表示：第一踏步、第二踏步、起跳台、完整落台、下坡接触（A不适用）、终点。另记录 `stairs_completed`、`jump_completed`、`downhill_contact`（仅B）、`success` 和 `frontier`。

`learn`从L0开始，沿用50次尝试、80%升档/40%以下降档的整段成功率课程。`standard`对这两类采用40% L6、40% L9、20% L7–L8。`eval`不改变等级，可指定L6验收或L9检查强化参数。比赛课程默认每回合45秒，继续使用0.15–0.30m/s前进指令。
