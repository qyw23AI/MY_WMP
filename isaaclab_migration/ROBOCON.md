# ROBOCON 九类课程地形（Isaac Lab / WMP / A1）

课程扩展位于 `isaaclab_migration`，保留策略、AMP、深度世界模型及285维观测接口。原 `mixed` 和旧 Isaac Gym 入口保持原有配置；比赛课程需要显式选择。最新梅花桩十五级及高墙、轮胎十级参数见 [OBSTACLE_CURRICULUM.md](OBSTACLE_CURRICULUM.md)，直线楼梯跳台组合参数见 [COMBO_TERRAINS.md](COMBO_TERRAINS.md)。比赛XML保持原文件内容。

## 几何与任务

两种梅花桩为L0–L14，L10为比赛基准、L14为最终目标；其他地形保持L0–L9，高墙、轮胎和楼梯组合以L6为比赛基准、L9为强化目标。几何、预览、深度射线和高度查询使用同一组三角网格。

| 类型 | 课程与终点 | 成功及失败规则 |
| --- | --- | --- |
| `plum_stones`（别名 `platform_plum_combo`） | 两端80×80×20cm高台＋六根20×20×20cm交错桩；仅间距课程，15级；相邻交错桩纵向−7.5→15cm、横向2.5→25cm，L10对齐比赛 | 两端高台和六桩均有真实顶面支撑；任意一脚落入桩间、侧面掉落或绕过高台失败 |
| `plum_stones_flat` | 同样的固定尺寸六桩与间距课程；进场、桩顶、离场同高，中间挖出20cm深的桩间凹槽，两端路面与桩也有1.5→15cm课程间隔；80cm宽，两侧深沟 | 六桩全部覆盖，桩间地面禁止落足；进出场地面合法 |
| `tire_array` | 固定外径55cm/内径33cm、2×4排列；只有高度3→19.8cm课程，始终中空；固定相对形状的浅凹坑碰撞 | 从短边进入、对侧离开；两足接触阵外地面失败，孔内真实地面接触合法 |
| `high_wall` | 宽80cm、厚8cm固定；高5→36cm，L6高30cm | 机身与四足完整越过，无侧绕，落地稳定；允许墙面接触，保留倒地和机身过低判定 |
| `platform` | 台面固定80×80cm，高5→30cm | 从地面上台、接触前后半区、对侧下台 |
| `ramp` | 5→30°上坡→80×80cm平台→同角度下坡；坡道宽80cm、水平长度各80cm | 按顺序取得上坡、平台前后半区和下坡的顶面支撑，然后离场 |
| `platform_gap` | 六个等高80×80cm平台、五个净间隔5→45cm，下方5m深沟 | 每段完整腾空，依次落到下一台；允许四足先后落地，落入间隙、跨步、跳过中间台或侧绕失败 |
| `stair_gap` | 直线上楼梯→80cm起跳台→缺口→80cm终点台；L9台阶18cm、缺口54cm | 按顺序完成楼梯和腾空落台，在末台稳定支撑 |
| `stair_gap_ramp` | 同样楼梯跳台→直线下坡→平地；L9下坡30° | 完成楼梯、跳台和下坡，在终点平地稳定支撑 |

梅花桩允许不同脚先后接触、支撑不同桩，每级均要求覆盖六桩，不要求四足同时落同一根桩。组合梅花桩平台和桩高固定20cm，桩面固定20cm，仅改变间距。两个方向的间隔均按相邻交错桩的边缘定义；同排桩距由交错布局推导，不能将同排40cm与相邻交错桩纵向10cm混为一谈。单独梅花桩是在同高路面中间挖出桩区，进出场路面与桩顶均为Z=20cm，槽底Z=0；组合任务进出场为Z=0。单独任务所有桩均与路面分离，两端路面与首尾桩的净间隔按1.5→10（L10）→15cm学习，任意脚落入这两处间隔同样失败。两类侧沟底均为Z=-5m，桩区任意脚落入间隙即失败。

轮胎所有等级没有内孔教学填充；只有高度是课程变量。浅凹坑使用固定的归一化形状，整体随高度缩放，最大深度为高度4%（L9约7.92mm），并参与碰撞。轮胎为固定刚体，不模拟橡胶变形；16.5cm为XML基准胎宽，真实平放高度仍需实测。

连续跳台的顶面局部Z=0、沟底Z=-5m，路径总长5.05–7.05m；从首台出生，在末台完成。每段四足无接触腾空后，累计四足各自的目标台顶面支撑；当前四足XY位于目标台内、至少两足支撑、四足越过上一台边缘后才记录该段完成。其余规则详见组合文档。楼梯组合没有90°转弯，路线两侧及缺口均为深沟。

## 课程、奖励和恢复

- `learn`：每类独立难度前沿，从L0开始；每级收集至少50次尝试，成功率≥80%升一级、<40%降一级，梅花桩最高L14，其他任务最高L9。
- `standard`：梅花桩两类按40% L10、40% L14、20% L11–L13采样；高墙、轮胎和楼梯组合按40% L6、40% L9、20% L7–L8采样；其余任务按60% L9、25% L7–L8、15% L0–L6采样。
- `eval`：默认按类型固定最高等级；梅花桩用 `--eval_terrain_level 10` 检查比赛基准、14检查最终目标，其余类型仍用6检查基准；重置不升降级。分别统计基准与强化成功率。
- 保留WMP速度跟踪与AMP奖励，加入最大前进距离增量、每桩首次接触、完成和违规事件奖励；覆盖记录与落脚目标不输入actor。
- A1足底按足球半径2cm估计，支撑力>1N，顶面接触需同时匹配位置和高度。成功需完成指定路径、至少两足支撑、姿态与竖直速度稳定0.3秒。
- 组合梅花桩从入口平台前0.7m地面出生，后脚仍在入口前地面时允许前脚上台；平地梅花桩从桩区前0.7m地面出生。出生扰动±2.5cm，近默认关节姿态、初速度0；连续跳台从首台出生。
- 比赛任务沿+X前进，速度指令0.15–0.30m/s、侧向指令0，不施加原版随机推力。默认回合上限45秒，可用 `--episode_seconds` 覆盖；旧 `plane/mixed` 仍默认20秒。
- 精确高度查询与分片三角曲面一致，保留187/525扫描点接口。深度相机对完整实际网格投射射线，不由稀疏扫描点合成图片。
- TensorBoard按任务记录成功、严格成功、覆盖、违规、失败、超时、课程前沿和标准尝试；每类每级累计计数保存在课程状态中。
- 课程检查点版本3（15列统计，兼容旧10列）按任务名和几何版本恢复。旧检查点的重建梅花桩、轮胎、高墙课程前沿与成绩重置；未改任务保留兼容计数，新任务从L0开始。网络与优化器恢复路径保留。仿真状态、轨迹缓存和随机数不是逐步完整恢复。

## 2026-10-19：早期1024环境训练记录（历史配置）

资源配置保持原网络、AMP、深度预测器和世界模型/优化器权重。1024环境中的256个使用64×64真实几何raycast深度，其余使用深度预测器；rollout48，世界模型批次4×64、每轮10次更新、启动阈值256（适配初期较短的失败回合），AMP预载/回放各100000；深度预测器每10轮更新1次，批次32。相对于旧检查点，显式缩小世界模型批次和AMP缓存，并降低深度预测器更新次数；未删除训练模块。训练回合上限45秒，保证0.15m/s慢速指令有时间从地面出发完成约5m的梅花桩任务；视频仍各20秒。CPU深度历史使用float32文件映射缓存 `replay/*.f32`，由OS回收页面，避免常驻占满32GB宿主内存。
