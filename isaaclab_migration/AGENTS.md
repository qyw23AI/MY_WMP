# 长时间训练运行约定

在本项目启动或恢复长时间训练时，使用用户的系统终端运行训练命令，并在终端显示实时日志，方便用户查看。不要只在后台或仅在 Codex 工具会话中启动训练。启动后核实实际训练 PID、日志和轮次进展。此约定来自用户于 2026-10-19 的明确要求。

长训练每累计 300 轮保存一次检查点。用户手动启动 `isaaclab_migration/record_course_checkpoints.sh` 后，对每个已保存的 300 轮检查点，逐个录制梅花桩、轮胎阵、高墙三类地形的 L0 和 L9，共六段回放。每段按 50 Hz 仿真时间采集真实的 20 fps、20 秒视频，镜头在机器人正后方朝向赛道；录像脚本不得自动启动或修改训练。
