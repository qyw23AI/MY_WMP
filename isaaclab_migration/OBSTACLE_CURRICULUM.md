# 梅花桩、高墙与轮胎阵课程（2026-10-20）

本次只修改障碍几何、任务规则及课程配置，不启动训练。保留已有随机粗糙地面，不新增坑洼地面类型。比赛尺寸参考 `/home/qyw/desktop/competition/robocon2027.v2.xml`，该文件未修改。

## 两种梅花桩任务

- `plum_stones`：入口高台 → 六根交错梅花桩 → 出口高台。兼容旧任务名；也可以使用更明确的别名 `platform_plum_combo`。
- `plum_stones_flat`：同高平地进场 → 中间挖出的六根交错梅花桩 → 同高平地离场，没有独立的上下高台。

两种任务的桩顶始终为 **20×20cm**，高度始终为 **20cm**；组合任务的两端高台始终为 **80×80×20cm**。仅间距参与课程。两种赛道均宽80cm、两侧为深沟。单独梅花桩的进场路面、桩顶、离场路面同为Z=20cm，中间挖去桩间区域形成固定20cm深的凹槽（槽底Z=0），侧沟底Z=-5m；没有上下桩的台阶。入口路面与第一根桩、最后一根桩与出口路面均完全分离，两端净间隔同样课程学习：L0为1.5cm、L10为10cm、L14为15cm，与表中的进出口间距一致。组合任务仍从Z=0地面上高台，再过桩和下高台。桩间及进出口间隙的槽底保留真实碰撞，但禁止落足；所有桩均不与路面直接连接。

任意一只脚在桩区落到低于桩面的地面，或脚落入桩间并低于顶面容差，立即判失败并重置；进出口两处间隔也适用，首次触桩前和覆盖全部桩后均不例外，两侧掉落同样失败。入口接近和完成后的同高路面落足合法（组合任务进出场地面仍为Z=0）。组合任务还要求经过两端高台，不能绕过高台。

允许不同脚先后接触、支撑不同桩；不要求四足同一控制步落在同一根桩。每级均要求六根桩全部出现有效顶面支撑接触，最终离开障碍区并稳定支撑0.3秒。桩覆盖记录仅用于奖励与判定，不作为策略的落脚点输入；深度观测来自训练碰撞网格的真实几何。

## 梅花桩十五级课程

仅两种梅花桩使用15级（L0–L14），其余地形保持原来的10级（L0–L9）。共享训练网格有15行，但非梅花桩列的第10–14行不生成障碍，也不会被课程或评估采样；旧地形的难度插值和十级课程保留。

以下单位均为cm。纵向、横向均指沿前进顺序相邻的交错桩在对应方向上的边缘净间隔；桩面固定20×20cm。中心纵向差为 `20 + 纵向净间隔`，中心横向差为 `20 + 横向净间隔`，同排净间隔为 `20 + 2×纵向净间隔`。

**L0纵向−7.5cm表示前后投影重叠7.5cm**，中心纵向差仍为12.5cm；横向净间隔2.5cm，使相邻交错桩实体完全分离。同排净间隔仍为5cm。训练碰撞、深度射线和高度查询均支持这种布局。

进出口路面/高台与首尾桩的间隔始终为正，独立从1.5cm增加到15cm，避免将负间隔用于进出口而把桩与平地连接。L0–L10同步递增到比赛几何，L10–L14继续递增到最终目标。

高墙宽80cm、厚8cm固定。轮胎外径55cm、内径33cm、2×4排列与中心间距固定，**所有等级始终中空，没有孔内教学填充**。轮胎只有高度参与课程。

## 轮胎凹凸碰撞

轮胎上半表面使用固定形状的浅凹坑三角网格，渲染、静态碰撞、深度射线和精确高度查询共享该几何。凹坑最大深度为当前轮胎高度的4%，L9约7.92mm；其相对形状和分布不随课程改变，整体随高度缩放。轮胎内孔保持开放，孔内真实地面接触仍合法。轮胎是固定刚体，不模拟橡胶变形。
